Exponential Information Gathering (EIG): Distributed Consensus Under Crash Faults

How path-labeled attribution trees eliminate asymmetric knowledge divergence in synchronous networks, establishing provable crash-stop consensus within exactly $f+1$ rounds.

22 min read Arpit Bhayani Distributed Systems Series Verified 3-Page Companion PDF
📥 Download Technical PDF (3 Pages)
📌 Core Architectural Takeaway: Knowledge Provenance Over Flat Information Sets

While the FloodSet algorithm solves distributed crash consensus by unioning values into a flat set, it discards provenance—the chain of custody detailing who reported what to whom. The Exponential Information Gathering (EIG) algorithm, pioneered by Lynch, Fischer, and Moses, structures distributed knowledge into an attribution tree of depth $f + 1$. Each tree node represents an explicit transmission path. By preserving the exact causal trail of message transit, surviving nodes detect exactly when and where a process died mid-broadcast, enabling unanimous bottom-up consensus reduction even in worst-case cascading failure cascades.

1. The Crash Consensus Challenge & Asymmetric Partitions

In a synchronous distributed system of $n$ distinct processes $\mathcal{P} = \{p_1, p_2, \dots, p_n\}$, each process starts with an initial private value $v_i \in V$. The cluster must agree on a single common output decision subject to three classic conditions:

  • Agreement: All non-faulty processes decide on the identical output value $v^* \in V$.
  • Validity: If all processes begin with the identical initial value $v$, then all non-faulty processes must decide $v$. If initial values differ, the decision must be in $V$.
  • Termination: All non-faulty processes terminate and output a decision within a bounded number of communication rounds.

The core difficulty under the Crash-Stop (Fail-Stop) model is the mid-broadcast failure. A node broadcasting its value $v_i$ to $n-1$ peers may abruptly crash after sending to a subset $S \subset \mathcal{P}$, leaving remaining peers in asymmetric states:

⚠️ The Hazard of Asymmetric Crash Observation

Suppose $p_1$ crashes midway through Round 1 while sending $v_1 = 1$. Nodes $p_2, p_3$ receive $1$, but nodes $p_4, p_5$ receive nothing ($\bot$). If processes were to decide immediately at the end of Round 1, $p_2, p_3$ would see $\{0, 1\}$ while $p_4, p_5$ would see $\{0\}$. If decisions are made on local observations alone, agreement is violated. Overcoming this requires propagating not just values, but who witnessed those values.

2. The EIG Tree Data Structure

In the EIG algorithm, each process $p_i$ maintains an internal tree $\mathcal{T}_i$ known as the Exponential Information Gathering Tree. The structure is defined as follows:

  • Tree Depth: Exactly $f + 1$ levels (rooted at level 0, extending to level $f+1$), where $f < n$ is the maximum number of crash failures the protocol is configured to tolerate.
  • Path Labeling: Each node in the tree is identified by a string $\alpha = j_1 j_2 \dots j_k$ of distinct process IDs, where $k$ is the tree depth ($1 \le k \le f+1$).
  • Semantic Meaning of Path $\alpha$: The label $\alpha = j_1 j_2 \dots j_k$ represents the value: $$\text{“Process } j_k \text{ reported to me that } j_{k-1} \text{ reported that } \dots \text{ that process } j_1 \text{ started with value } v_{j_1}\text{.”}$$
  • Root Node ($\lambda$): The empty string $\lambda$, representing the unassigned global consensus decision space.
  • Node Values: For each node $\alpha$, the process stores a value $val(\alpha) \in V \cup \{\bot\}$, where $\bot$ explicitly denotes that no message was received (either the process crashed or an ancestor in the path crashed).

3. Step-by-Step EIG Protocol Execution

The EIG protocol operates across strictly synchronous rounds $r = 1, 2, \dots, f + 1$, followed by a local bottom-up tree evaluation step:

Round 1: Initial State Broadcast

  1. Each process $p_i$ broadcasts its initial value $v_i \in V$ to all peers in $\mathcal{P}$.
  2. For every process $p_j \in \mathcal{P}$:
    • If a valid message $v_j$ is received from $p_j$, set $val_i(j) \leftarrow v_j$.
    • If no message is received (timeout indicating crash), set $val_i(j) \leftarrow \bot$.

Round $r$ ($2 \le r \le f + 1$): Attributed Path Exchange

  1. Each surviving process $p_i$ constructs a message containing all node labels and values at level $r - 1$ of its EIG tree: $$\mathcal{M}_i^{(r)} = \{ (\alpha, val_i(\alpha)) \mid |\alpha| = r - 1 \}$$
  2. Process $p_i$ broadcasts $\mathcal{M}_i^{(r)}$ to all peers.
  3. Upon receiving $\mathcal{M}_j^{(r)}$ from peer $p_j$, for each pair $(\alpha, v) \in \mathcal{M}_j^{(r)}$ where process $j$ does not appear in path $\alpha$: $$val_i(\alpha \cdot j) \leftarrow v$$
  4. If no message was received from $p_j$ in Round $r$, then for all eligible prefixes $\alpha$: $$val_i(\alpha \cdot j) \leftarrow \bot$$

4. Decision Rule: Bottom-Up Tree Reduction

Once Round $f + 1$ completes, each non-faulty process $p_i$ performs an identical, deterministic bottom-up resolution on its tree $\mathcal{T}_i$ to assign a resolved value $newval_i(\alpha)$ to each node, culminating in the root decision $newval_i(\lambda)$:

📐 Formal Bottom-Up Reduction Operator

For any node $\alpha$ with depth $|\alpha|$:

1. Base Case (Leaves at Level $f + 1$):

$$newval_i(\alpha) = \begin{cases} val_i(\alpha) & \text{if } val_i(\alpha) \neq \bot \\ v_{\text{default}} & \text{if } val_i(\alpha) = \bot \end{cases}$$

2. Inductive Step (Internal Nodes from Level $f$ down to Level 0):

Let $C(\alpha) = \{ newval_i(\alpha \cdot j) \mid j \notin \text{nodes}(\alpha) \}$ be the set of resolved values of $\alpha$'s children. If all values in $C(\alpha)$ are identical to some single value $v \in V$, then:

$$newval_i(\alpha) = v$$

Otherwise, if there is a conflict or multiple distinct values exist in $C(\alpha)$, $p_i$ applies the fixed tie-breaker rule:

$$newval_i(\alpha) = \min(C(\alpha)) \quad (\text{or default } v_{\text{default}})$$

3. Terminal Output: Process $p_i$ outputs the decision $v^* = newval_i(\lambda)$.

5. Executable Reference Implementation

Below is a clean, self-contained Python 3 implementation demonstrating the complete EIG tree construction, mid-broadcast crash simulation, and bottom-up reduction rule:

from typing import Dict, Optional, Set, List

class EIGCrashConsensusNode:
    def __init__(self, node_id: int, total_nodes: int, max_crashes: int, initial_val: int):
        self.id = node_id
        self.n = total_nodes
        self.f = max_crashes
        self.initial_val = initial_val
        self.is_alive = True
        
        # Raw received tree values: key is path tuple e.g. (1,) or (1, 2)
        self.val: Dict[tuple, Optional[int]] = {}
        # Resolved values computed during bottom-up reduction
        self.newval: Dict[tuple, int] = {}
        self.default_val = 0

    def round_1_broadcast(self) -> Optional[int]:
        return self.initial_val if self.is_alive else None

    def round_1_receive(self, messages: Dict[int, Optional[int]]):
        for peer_id in range(1, self.n + 1):
            val = messages.get(peer_id)
            self.val[(peer_id,)] = val  # None represents bot (crashed)

    def round_r_send(self, current_round: int) -> Optional[Dict[tuple, Optional[int]]]:
        if not self.is_alive:
            return None
        # Return all entries in EIG tree at level current_round - 1
        level = current_round - 1
        return {path: v for path, v in self.val.items() if len(path) == level}

    def round_r_receive(self, current_round: int, incoming: Dict[int, Optional[Dict[tuple, Optional[int]]]]):
        expected_len = current_round - 1
        for peer_id in range(1, self.n + 1):
            peer_payload = incoming.get(peer_id)
            # Iterate through all existing paths at level - 1
            for path in list(self.val.keys()):
                if len(path) == expected_len and peer_id not in path:
                    new_path = path + (peer_id,)
                    if peer_payload is not None and path in peer_payload:
                        self.val[new_path] = peer_payload[path]
                    else:
                        self.val[new_path] = None  # Peer died or dropped message

    def compute_decision(self) -> int:
        """Evaluates tree bottom-up from depth f + 1 to root ()"""
        # Step 1: Base Case for Leaves at depth f + 1
        for path, v in self.val.items():
            if len(path) == self.f + 1:
                self.newval[path] = v if v is not None else self.default_val

        # Step 2: Inductive bottom-up reduction for levels f down to 0
        for level in range(self.f, -1, -1):
            paths_at_level = [p for p in self.val.keys() if len(p) == level]
            if level == 0:
                paths_at_level = [()]

            for path in paths_at_level:
                # Find all children: path + (j,)
                children_vals = [
                    self.newval[path + (j,)]
                    for j in range(1, self.n + 1)
                    if j not in path and (path + (j,)) in self.newval
                ]
                if not children_vals:
                    self.newval[path] = self.default_val
                elif all(cv == children_vals[0] for cv in children_vals):
                    self.newval[path] = children_vals[0]
                else:
                    self.newval[path] = min(children_vals)

        return self.newval[()]  # Consensus decision at root

6. Formal Correctness & Proof of Agreement

The mathematical guarantee that all surviving processes output the exact same value relies on the Clean Round Invariant:

Theorem: Consensus Agreement in f + 1 Rounds

In any synchronous execution where at most $f$ processes crash, all non-faulty processes terminate after $f+1$ rounds and satisfy $newval_i(\lambda) = newval_j(\lambda)$ for all non-faulty $p_i, p_j$.

Proof Sketch by the Pigeonhole Principle

  1. The Existence of a Clean Round: A process can crash at most once. If up to $f$ processes crash across $f + 1$ rounds of execution, by the Pigeonhole Principle, there must exist at least one round $k \in \{1, 2, \dots, f + 1\}$ in which zero processes crash. This round $k$ is designated as the Clean Round.
  2. Identical Level $k$ Broadcasts: In clean round $k$, every process that is alive at the start of round $k$ successfully transmits its level $k-1$ tree contents to all other living processes. No messages are lost or dropped.
  3. Knowledge Synchronization: Consequently, for every path $\alpha$ of length $k$, every non-faulty process $p_i$ and $p_j$ records identical values: $$val_i(\alpha) = val_j(\alpha)$$
  4. Determinism of Descendants: All subsequent messages at rounds $k+1, \dots, f+1$ are deterministic re-transmissions of these identical values. Any process that crashes in later rounds cannot distort the previously synchronized values.
  5. Bottom-Up Invariance: During bottom-up reduction, any node $\alpha$ with $|\alpha| = k$ evaluates to the exact same value across all non-faulty nodes: $$newval_i(\alpha) = newval_j(\alpha)$$ By induction, this consensus propagates all the way up to the root: $$newval_i(\lambda) = newval_j(\lambda) = v^*$$

7. Complexity Analysis & The EIG Explosion

Metric EIG Algorithm (Crash Model) FloodSet Algorithm Paxos / Raft (Async)
Rounds to Decision $f + 1$ rounds (Strictly optimal) $f + 1$ rounds (Strictly optimal) 1–2 RTTs typical; unbounded worst-case
Tree / State Size $O(n^{f+1})$ nodes (Exponential explosion) $O(|V|)$ flat values (Linear / Minimal) $O(L)$ log entries
Message Size $O(n^{f})$ bits per message $O(|V|)$ bits per message $O(\text{batch size})$

8. Systems Engineering Takeaways

  1. EIG is a Theoretical Blueprint: While the $O(n^{f+1})$ message size makes EIG impractical for raw production storage systems compared to FloodSet or Paxos, its strict path attribution is the indispensable foundation for proving Byzantine Agreement.
  2. Lower Bound Irreducibility: No deterministic consensus algorithm can guarantee agreement under $f$ crash faults in fewer than $f+1$ rounds in synchronous networks. Whether using lightweight FloodSet or attribution-rich EIG, systems must pay the $f+1$ round latency penalty.
  3. Bridging to Byzantine Faults: In a crash model, a node cannot lie—it can only withhold messages ($\bot$). In the Byzantine model, nodes can actively lie and send conflicting values. Because EIG records who told what, it allows recursive majority voting to filter out traitors, which flat sets cannot do.
