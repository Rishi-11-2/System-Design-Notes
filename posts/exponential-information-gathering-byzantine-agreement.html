Exponential Information Gathering (EIG): Byzantine Agreement Algorithm

How recursive majority voting over path-attributed EIG trees neutralizes malicious disinformation, establishing provable consensus when $n \ge 3f + 1$.

24 min read Arpit Bhayani Distributed Systems Series Verified 3-Page Companion PDF
📥 Download Technical PDF (3 Pages)
📌 Core Theoretical Breakthrough: Defeating Malice Through Attributed Majority Voting

Under the Byzantine failure model, faulty nodes are not merely dead (crash-stop); they can actively lie, transmit contradictory values to different peers, forge messages, and collude. Lamport, Shostak, and Pease proved that Byzantine Agreement without digital signatures is mathematically impossible unless $n \ge 3f + 1$. The Exponential Information Gathering (EIG) Algorithm for Byzantine Agreement constructs an attribution tree of depth $f + 1$ and applies Recursive Strict Majority Voting from the leaves to the root. Because loyal processes strictly outnumber Byzantine traitors at every step of uncorrupted prefixes, the loyal majority systematically filters out malicious fabrications.

1. The Byzantine Agreement Problem Formulation

In a synchronous network of $n$ processes $\mathcal{P} = \{p_1, p_2, \dots, p_n\}$, up to $f$ processes are Byzantine (faulty). Non-faulty processes are termed loyal (or correct). Each process begins with a private initial input $v_i \in V$. The cluster must guarantee:

  • Agreement: All loyal processes decide on the identical output value $v^* \in V$.
  • Validity: If all loyal processes start with the identical initial value $v$, then all loyal processes must decide $v$. In the classic Byzantine Generals formulation (single Commander $C$), if $C$ is loyal with input $v$, every loyal lieutenant must decide $v$.
  • Termination: All loyal processes output their decision and terminate within $f + 1$ synchronous rounds.

2. The $n \ge 3f + 1$ Impossibility Bound

Before introducing the algorithm, we examine why consensus cannot be achieved when $n \le 3f$ in unauthenticated synchronous networks:

⚠️ Why 3 Nodes Cannot Tolerate 1 Traitor ($n = 3, f = 1$)

Consider 3 nodes: Commander $C$, Lieutenant $L_1$, and Lieutenant $L_2$. Suppose $f = 1$:

  • Scenario A (Commander is Traitor): Traitor $C$ sends order Attack (1) to $L_1$ and order Retreat (0) to $L_2$. When $L_1$ asks $L_2$ what $C$ said, $L_2$ truthfully answers "0". $L_1$ sees conflicting orders: $C$ said 1, but $L_2$ says $C$ said 0.
  • Scenario B ($L_2$ is Traitor): Commander $C$ is loyal and sends Attack (1) to both $L_1$ and $L_2$. Traitor $L_2$ lies to $L_1$, claiming "Commander told me 0". From $L_1$'s perspective, the incoming messages are identical to Scenario A!

Because $L_1$ cannot distinguish whether the Commander is lying or $L_2$ is lying, it cannot safely choose 1 without risking agreement in Scenario A, nor choose 0 without violating validity in Scenario B. Thus, $n \ge 3f + 1$ is an absolute mathematical lower bound.

3. The EIG Byzantine Tree Architecture

In the Byzantine EIG algorithm, each process $p$ maintains an EIG tree $\mathcal{T}_p$ of height $f + 1$:

  • Tree Depth: Exactly $f + 1$ rounds of communication, resulting in tree depth $f + 1$ (Level 0 through Level $f+1$).
  • Path Labels: A node is labeled by a sequence $\alpha = j_1 j_2 \dots j_k$ of distinct process indices with $1 \le k \le f+1$.
  • Semantics: $\alpha$ represents: "$j_k$ tells me that $j_{k-1}$ tells me ... that $j_1$ started with $v_{j_1}$."
  • Stored Value: $val_p(\alpha) \in V \cup \{\bot\}$. If a process dropped a message or sent a malformed packet, it is recorded as $\bot$.

4. Protocol Execution & Recursive Majority Rule

The EIG Byzantine agreement algorithm proceeds in two phases: Information Gathering across $f + 1$ synchronous rounds, followed by local Recursive Majority Reduction.

Phase 1: Information Gathering ($f + 1$ Rounds)

  1. Round 1: Each process $p$ broadcasts its initial input value $v_p$ to all other processes. Upon receiving values, $p$ initializes level 1 of $\mathcal{T}_p$: $$val_p(j) \leftarrow \text{received value from } p_j \quad (\text{or } \bot \text{ if missing/corrupt})$$
  2. Round $r$ ($2 \le r \le f + 1$): Each process $p$ broadcasts all node pairs $(\alpha, val_p(\alpha))$ from level $r - 1$. For each received message from peer $j$ and for each path $\alpha$ where $j \notin \text{nodes}(\alpha)$: $$val_p(\alpha \cdot j) \leftarrow \text{value reported by } j \text{ for path } \alpha$$

Phase 2: Recursive Strict Majority Reduction

After round $f + 1$, each loyal process $p$ computes resolved values $newval_p(\alpha)$ bottom-up from leaves to root:

📐 Formal Reduction Operator: resolve_byzantine(node)

1. Base Case (Leaves at depth $f + 1$):

$$newval_p(\alpha) = \begin{cases} val_p(\alpha) & \text{if } val_p(\alpha) \in V \\ v_{\text{default}} & \text{if } val_p(\alpha) = \bot \text{ or invalid} \end{cases}$$

2. Inductive Step (Internal nodes from depth $f$ down to 0):

For node $\alpha$, let $S = \{ newval_p(\alpha \cdot j) \mid j \notin \text{nodes}(\alpha) \}$ be the multiset of resolved child values.

  • If there exists a value $v \in V$ that occurs strictly more than $\frac{|S|}{2}$ times in $S$: $$newval_p(\alpha) = v$$
  • Otherwise (no strict majority exists due to split traitor votes): $$newval_p(\alpha) = v_{\text{default}}$$

3. Terminal Output: Process $p$ outputs $v^* = newval_p(\lambda)$.

5. Executable Reference Implementation

Here is an executable Python 3 implementation modeling 4 processes with 1 Byzantine traitor sending contradictory values, resolved by EIG strict majority:

from collections import Counter
from typing import Dict, List, Optional, Tuple

class EIGByzantineNode:
    def __init__(self, node_id: int, n: int, f: int, initial_val: int, is_traitor: bool = False):
        self.id = node_id
        self.n = n
        self.f = f
        self.initial_val = initial_val
        self.is_traitor = is_traitor
        self.default_val = 0
        
        # Raw received values: path tuple -> int or None
        self.val: Dict[Tuple[int, ...], Optional[int]] = {}
        # Bottom-up resolved values: path tuple -> int
        self.newval: Dict[Tuple[int, ...], int] = {}

    def round_1_send(self, target_id: int) -> int:
        if self.is_traitor:
            # Traitor actively lies: sends 1 to even nodes, 0 to odd nodes
            return 1 if (target_id % 2 == 0) else 0
        return self.initial_val

    def round_1_receive(self, incoming: Dict[int, int]):
        for sender_id, v in incoming.items():
            self.val[(sender_id,)] = v

    def round_r_send(self, target_id: int, current_round: int) -> Dict[Tuple[int, ...], int]:
        level = current_round - 1
        payload = {path: v for path, v in self.val.items() if len(path) == level and v is not None}
        if self.is_traitor:
            # Traitor mutates payload to invert truth
            return {path: (1 - v if v in (0, 1) else v) for path, v in payload.items()}
        return payload

    def round_r_receive(self, current_round: int, incoming_payloads: Dict[int, Dict[Tuple[int, ...], int]]):
        expected_len = current_round - 1
        for sender_id, payload in incoming_payloads.items():
            for path, v in payload.items():
                if len(path) == expected_len and sender_id not in path:
                    self.val[path + (sender_id,)] = v

    def resolve_tree(self) -> int:
        """Bottom-up recursive majority voting from depth f+1 to root ()"""
        # Step 1: Base Case at leaves (depth f+1)
        for path, v in self.val.items():
            if len(path) == self.f + 1:
                self.newval[path] = v if v is not None else self.default_val

        # Step 2: Levels f down to 0
        for level in range(self.f, -1, -1):
            paths_at_level = [p for p in self.val.keys() if len(p) == level]
            if level == 0:
                paths_at_level = [()]

            for path in paths_at_level:
                children = [
                    self.newval[path + (j,)]
                    for j in range(1, self.n + 1)
                    if j not in path and (path + (j,)) in self.newval
                ]
                if not children:
                    self.newval[path] = self.default_val
                    continue

                # Strict majority test
                counts = Counter(children)
                majority_val, top_count = counts.most_common(1)[0]
                if top_count > len(children) // 2:
                    self.newval[path] = majority_val
                else:
                    self.newval[path] = self.default_val

        return self.newval[()]  # Cluster decision

6. Formal Correctness & Proof of Agreement

Theorem: Byzantine Agreement Under $n \ge 3f + 1$

In any synchronous network with $n \ge 3f + 1$ processes of which at most $f$ are Byzantine, all loyal processes terminate after $f + 1$ rounds and satisfy:

  1. Agreement: $newval_p(\lambda) = newval_q(\lambda)$ for all loyal $p, q$.
  2. Validity: If all loyal processes have initial input $v$, then $newval_p(\lambda) = v$ for all loyal $p$.

Proof Sketch by Backward Induction on the EIG Tree

  1. Definition of Loyal Path: A path label $\alpha = j_1 j_2 \dots j_k$ is called loyal if the last process $j_k$ is a loyal (non-faulty) process.
  2. Lemma 1 (Common Value on Loyal Nodes): If $\alpha$ is a loyal node, then for all loyal processes $p$ and $q$: $$val_p(\alpha) = val_q(\alpha) \quad \text{and} \quad newval_p(\alpha) = newval_q(\alpha)$$ Proof: Since $j_k$ is loyal, it faithfully broadcasts the identical message to all peers in round $k$. Therefore, every loyal process receives and stores the exact same value.
  3. Lemma 2 (Pigeonhole Guarantees Loyal Ancestor): Every path from root to leaf has length $f + 1$. Because there are at most $f$ Byzantine processes, by the Pigeonhole Principle, every path of length $f + 1$ contains at least one loyal node.
  4. Lemma 3 (Strict Majority Overrides Traitors): At any internal node $\alpha$ whose prefix consists solely of traitors, the number of children is $|C(\alpha)| = n - |\alpha|$. Since $|\alpha| \le f$ and $n \ge 3f + 1$: $$|C(\alpha)| \ge (3f + 1) - f = 2f + 1$$ Of these remaining candidates, at most $f$ can be Byzantine. Therefore, the loyal children number at least: $$\text{Loyal Children} \ge (2f + 1) - f = f + 1 > \frac{|C(\alpha)|}{2}$$ The loyal children form a strict majority over the Byzantine children. Thus, recursive majority voting guarantees that the true value prevails.
  5. Inductive Conclusion: Applying Lemma 3 inductively upward from the deepest loyal nodes guarantees that all loyal processes compute identical values for all ancestors, culminating in $newval_p(\lambda) = newval_q(\lambda) = v^*$.

7. Complexity Analysis & Comparison

EIG Crash Crash-Stop $n \ge f + 1$ $f + 1$ rounds $O(n^{f+1})$ messages

8. Systems Engineering Takeaways

  1. The 3f + 1 Rule is Non-Negotiable: Without cryptographic digital signatures, a distributed system cannot withstand $f$ Byzantine actors unless at least $2f + 1$ loyal actors exist to form a strict majority over the traitors.
  2. The Cost of Byzantine Resilience: While crash fault tolerance only requires $n \ge f + 1$, Byzantine resilience requires $n \ge 3f + 1$—more than triple the redundancy. This explains why modern blockchain networks and aerospace avionics maintain strict node quotas.
  3. EIG to PBFT Evolutionary Line: While EIG's tree structure is too heavy for high-throughput transactional databases due to $O(n^{f+1})$ exponential explosion, its core insight—using recursive quorum quorums to mask lies—directly inspired practical algorithms like PBFT, Raft-BFT, and Tendermint.
